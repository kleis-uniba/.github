- Prediction explanation
- Integration of LLMs: RAG and prompt engineering
- Web Ontologies
- Reasoning under uncertainty
- Evidence-based classification of instances
- Probabilistic ontologies and interpretable models
- Ontology learning
- Linked Data
- Description Logics: representation and reasoning
- Concept Learning
